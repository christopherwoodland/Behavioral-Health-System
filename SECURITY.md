# Security Policy

## Reporting a Vulnerability

Do not report security vulnerabilities through public GitHub issues.

Use GitHub's private vulnerability reporting for this repository:

<https://github.com/christopherwoodland/Behavioral-Health-System/security/advisories/new>

Include the affected component and version, reproduction steps, potential impact, and any known mitigations. Do not include real patient data, credentials, access tokens, or other sensitive information.

The maintainers will acknowledge a complete report as soon as practical, investigate it, and coordinate remediation and disclosure. Public disclosure should wait until a fix or mitigation is available.

## Supported Versions

Security fixes are applied to the default branch. Tagged releases are supported only when explicitly identified in their release notes.

## Clinical and Privacy Safety

MindBridge is decision-support software, not an emergency service or an autonomous diagnostic system. Security reports involving protected health information, patient safety, authentication, authorization, audit logging, model prompt injection, or unsafe AI output should be identified clearly so they can be prioritized.
