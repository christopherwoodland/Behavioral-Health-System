# Support

## Questions and Troubleshooting

Search existing GitHub issues and the project documentation before opening a new issue. For reproducible defects, use the bug report template and include sanitized logs, environment details, and the smallest reproduction available.

This open-source project is maintained on a best-effort basis. It does not include a service-level agreement or clinical support commitment.

## Security and Sensitive Data

Do not post credentials, access tokens, patient information, protected health information, or security vulnerabilities in public issues. Follow [SECURITY.md](SECURITY.md) for private vulnerability reporting.

## Clinical Emergencies

MindBridge is not an emergency service. Do not use repository support channels for urgent clinical situations. Contact local emergency services or an appropriate qualified professional.
